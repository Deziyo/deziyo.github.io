全局洞察

本次 Build 2026 不是一次常规的产品迭代发布会，而是微软战略转向的宣言——从"应用程序的操作系统"到"AI Agent 的运行时环境"。底层逻辑是：如果 AI 正在从被动问答进化为自主执行，那么操作系统需要从"应用容器"进化为"Agent 容器"。这条主线贯穿了从硬件（RTX Spark）到安全（MXC 沙箱）、从框架（WAF/OpenClaw）到分发（Agent Store）的全部发布。

值得追问的是：这条路径是否过于超前？Agent 对普通用户的真实价值尚未被充分验证，微软却已经在全栈推进基础设施。这是前瞻性布局还是过度投资？——这个问题可能要到 2027 年才有答案。

硬件革命：NVIDIA RTX Spark 与 Surface 开发者设备

00:00 – 02:10
00:00
开场：Build 2026 主题定调

视频以大会全景切入，快速锚定本次 Build 的核心叙事——Agent-First。微软 CEO 纳德拉将 AI Agent 定位为"新一代计算的基本单位"，而非传统意义上的应用功能叠加。

  • 开场即抛出核心命题：Windows 不是为 Agent 加功能，而是以 Agent 为操作系统设计原语
  • 这个定调不是修辞技巧，而是贯穿后续 20+ 项发布的一致逻辑
Nova 思考当一家公司开始用"原语"（primitive）而非"功能"（feature）来描述某项技术时，意味着它已进入架构层面的重构。这通常比功能叠加慢得多，但一旦完成，护城河也深得多。
00:43
NVIDIA RTX Spark 超级芯片发布

NVIDIA CEO 黄仁勋远程连线，正式发布 RTX Spark——英伟达首款面向 Windows PC 的 Arm 架构 AI 超级芯片。这是高通骁龙 X 系列之外，Windows on Arm 生态的第二个重磅玩家。

  • 规格台积电 3nm 制程，SoC 单芯片集成 20 核 Grace CPU（联发科联合研发）+ Blackwell RTX GPU（6144 CUDA）+ 独立 NPU
  • 规格最高 128GB 统一 LPDDR5X 内存（CPU/GPU/NPU 共享内存池）
  • 规格AI 算力标称 1 petaFLOP（千万亿次/秒），可本地运行 120B 参数大模型
  • 规格1440p 3A 游戏 100+ FPS（DLSS 4.5），支持 12K 视频编辑和 90GB+ 3D 场景渲染
  • 生态Adobe 全系（PS/Premiere）已完成架构级适配，性能最高提升 2 倍
Nova 思考RTX Spark 真正的战略意义不在于参数规格，而在于它打破了高通在 Windows on Arm 领域的独供格局。一旦 NVIDIA + 联发科入局，Windows on Arm 就从"高通的实验"变成了"行业标准方向"。同理，苹果 M 系列的成功也建立在软硬一体化 + 统一内存架构上——NVIDIA 正在复刻这条路径，但面向的是开放的 Windows 生态。
01:14
Surface RTX Spark Dev Box 开发者工作站

微软发布搭载 RTX Spark 芯片的 Surface 开发者盒子，定位为"开发者本地 AI 工作站"。支持同时运行 3 个大模型（最大 1200 亿参数），GPU 占用 90GB 内存处理 340 万 token。

  • 首批搭载设备为轻薄本形态：14mm 厚度、约 1.36kg、OLED 屏幕（14/16 英寸）
  • 合作 OEM 包括华硕、戴尔、惠普、联想、微软 Surface、微星
  • 2026 年秋季正式发售
  • 战略从此 Apple Silicon 不再是唯一能跑大模型的轻薄 PC——Windows 第一次在移动端拥有匹敌 M 系列的本地 AI 算力

AI Agent 操作系统：Project Solara

07:53 – 08:58
07:53
Project Solara 正式发布

微软发布 Project Solara——基于 AOSP（Android 开源项目）构建的全新操作系统，核心设计理念是：不是运行传统的"应用程序"（Apps），而是专为"智能体"（Agents）打造。

  • 颠覆性设计：屏幕不再是主要交互界面，Agent 是操作系统的一等公民
  • 配套两款概念设备：桌面便携立方体（带触控屏 + 语音激活）+ 可穿戴 AI 门禁徽章（指纹解锁 + 摄像感知）
  • 目前仅内部试点（数百名微软员工），暂无量产计划
  • 战略如果 Windows 是"笔记本 + 桌面"的操作系统，Solara 则是"AI 可穿戴 + 万物互联"的操作系统
  • 风险隐私合规是最大拦路虎——全天候感知环境的可穿戴设备，数据存储和使用边界尚未明确
Nova 思考Solara 是本届 Build 最激进的项目，也是最具不确定性的。它试图在新硬件形态（后手机时代）定义新的操作系统范式——就像 2007 年 iOS 重新定义了触屏交互。但问题在于：Agent 的价值主张远不如"触屏"直观，用户能否接受"把工作交给一个看不见的 Agent"还有很大疑问。微软在 HoloLens 上的教训已经证明：技术领先不等于市场接受。
08:58

纳德拉在舞台上展示了 Solara 设备的概念原型：小巧的立方体设备放置在办公桌上，实时显示 Agent 的工作进度；可穿戴徽章支持语音唤醒和环境感知。

数据与搜索基础设施

10:24 – 14:17
10:24
Azure Horizon DB — 新一代数据库服务

Azure 推出 Horizon DB，定位为 Agent 时代的多模态数据存储层，支持结构化、半结构化和非结构化数据的统一管理。

11:10
Web IQ — 专为 AI 打造的搜索 API

微软发布 Microsoft Web IQ——一套专门为 AI Agent 设计的搜索 API，与人类使用的传统搜索引擎工作方式完全不同。

  • 核心差异：返回结构化数据而非网页链接，减少 Agent 的 Token 消耗
  • 提供上下文信息、网页文档、新闻、图片和视频等多种内容类型
  • 由微软搜索与 AI 部门总裁 Jordi Ribas 主导
  • 战略搜索引擎正在分化——面向人类的搜索（Bing/Google）和面向 Agent 的搜索（Web IQ）。这背后是一个关键认知：Agent 需要的信息格式和人类完全不同，让它去"读网页"是低效的
  • 风险如果 Web IQ 成为 Agent 获取信息的唯一渠道，微软将控制 AI 的信息入口——这是比浏览器市场份额更底层的入口竞争

Agent 安全与开源框架

14:17 – 17:12
14:17
Microsoft Execution Containers（MXC）— 内核级 Agent 沙箱

MXC 是本届 Build 最具技术含量的发布之一——在操作系统内核层为 Agent 操作提供强制执行边界，将权限控制从"应用层自律"升级为"内核强制执行"。

  • 四档隔离级别，可根据 Agent 的信任等级动态调整权限范围
  • 演示案例：OpenClaw Agent 尝试删除桌面 94 张图片，被 MXC 只读沙箱成功拦截
  • SDK 早期预览版面向 Windows 及 WSL 平台发布
  • 已开源至 GitHub（microsoft/mxc）
  • 合作伙伴包括 OpenAI、NVIDIA、Manus、Nous Research、OpenClaw
  • 战略Agent 安全问题不是"功能"而是"前置条件"。如果一个 Agent 能自主读写文件、调用 API、发邮件，那么没有内核级沙箱的约束，企业就不可能大规模部署。MXC 是微软抢在"Agent 安全事故"爆发前建立的行业标准
Nova 思考与 Docker 的应用层隔离不同，MXC 的"内核强制执行"意味着即使 Agent 试图绕过限制，操作系统本身也会阻止它。这种安全模型在金融、医疗等合规敏感行业是 Agent 商用的前提条件。微软正在用操作系统层面的安全能力建立竞争壁垒——这是 Google（ChromeOS）和 Apple（macOS/iOS）已有的能力，但微软率先将其应用于 Agent 场景。
14:40
OpenClaw 正式进入 Windows 生态

开源 Agent 框架 OpenClaw（GitHub 29.5 万星标）获得微软官方支持，成为 Windows Agent Framework 的重要组成部分。

  • 同步成立 OpenClaw Foundation（非营利组织），确保框架的开放中立性
  • OpenClaw 主导者 Peter Steinberger 登台
  • 战略微软没有重新发明轮子，而是选择"收编"最成功的开源 Agent 框架——这是平台公司的经典策略：把生态中最有活力的部分纳入自己的轨道

21:20
Microsoft Scout — 永不休眠的个人 AI 代理

Scout 是本届 Build 最具商业想象力的产品——一个"永不休眠"的 AI 代理，常驻 Microsoft 365 应用中，主动跨应用管理工作。

  • 可加入 Teams 群聊，作为独立参与者存在
  • 常驻 Outlook，自主处理邮件分类和回复
  • 拥有独立身份和 Microsoft 365 生产力许可证
  • 支持 7×24 小时运行

AI 模型、量子与未来展望

22:12 – 23:50
22:12
新 MAI 模型家族发布

微软 MAI 模型系列迎来 v2 重大升级，涵盖图像、语音、代码和推理四项能力，标志着微软在模型层面正式走向"全栈自研"。

  • MAI-Thinking-1：推理模型，AIME 2025 数学推理达 97%（接近人类顶尖），SWE-bench Pro 53%（软件工程仍有空间）
  • MAI-Image-2.5：新增图像输入能力，支持编辑工作流，对标 GPT-4o 图像功能
  • MAI-Voice-2：扩展至 15 种语言（含中文），支持更丰富的情感语调
  • MAI-Transcribe-1.5：FLEURS 测试 25 种语言最低词错误率 3.9%，已击败 Whisper
  • 强调"零蒸馏"——使用企业级商用授权数据从零训练，在合规性上做差异化
  • 战略MAI 系列背后是微软与 OpenAI 关系的再定义。Project Polaris 已宣布将在 2026 年 8 月取代 GPT-4 Turbo 成为 Copilot 默认模型——这意味着微软正在坚决执行"摆脱 OpenAI 依赖"的战略
Nova 思考微软与 OpenAI 的关系正在从"合作伙伴"转变为"竞合关系"。一个关键信号是：MAI 系列强调"零蒸馏"（不使用 OpenAI 输出训练），这表明微软在法律和商业上都希望建立完全独立于 OpenAI 的模型能力。对 OpenAI 来说，失去 Copilot 这个最大应用场景，压力巨大。
23:40
微软 × 梅奥诊所 — 健康 AI 模型

微软与全球顶级医疗机构梅奥诊所（Mayo Clinic）合作开发专用健康 AI 模型。这是 AI 在垂直行业深度应用的典型案例——医疗领域对模型准确性、合规性和可解释性的要求远超通用场景。

23:50
Majorana 2 — 量子计算里程碑

微软发布第二代拓扑量子芯片 Majorana 2，将量子计算实用化时间表大幅提前至 2029 年。

  • 突破量子比特可靠性提升 1000 倍，比特寿命从 1-12 毫秒提升至 20 秒以上（部分可达分钟级）
  • 材料超导体从铝升级为铅；半导体活性区域升级为砷化铟 + 砷化铟锑组合
  • 研发过程中使用微软自研 Discovery Agent AI 辅助设计
  • 战略拓扑量子比特的优势在于天然抗噪声——这是实用量子计算的最大技术障碍。如果微软在 2029 年兑现承诺，这将是量子计算赛道中第一个可商用的拓扑量子芯片
  • 风险学界对微软拓扑量子比特的声明仍有争议（Nature 2025 年曾发表质疑文章），技术路线尚未得到独立第三方充分验证
Nova 思考量子计算和 AI 的关系常被忽略。如果 Majorana 2 路线走通，大规模量子计算机将彻底改变 AI 训练的算力约束——目前受限于 GPU 集群的训练范式将不再成立。这意味着今天的 AI 模型架构可能只是算力受限阶段的"临时方案"。但这是至少 5-10 年后的故事，短期内仍需关注 GPU 和 NPU 的演进。

核心战略转变

从"应用操作系统"到"Agent 运行时环境"——硬件（RTX Spark）、安全（MXC）、框架（WAF/OpenClaw）、分发（Agent Store）四层全栈布局。

去 OpenAI 化

Project Polaris 8 月取代 GPT-4 Turbo，MAI 系列强调"零蒸馏"，自研 Maia 200 芯片提供推理底座——微软正在坚决建立独立 AI 能力。

商业模式升级

Scout"数字员工"需要独立许可证，Agent Store 提供 85% 分成——AI 从"增值功能"变为"独立收入线"。

前瞻性布局

Solara 定义后手机时代的交互范式，Majorana 2 锁定 2029 年量子商用——微软正在同时押注中期（Agent）和长期（量子）未来。

最大的风险

Agent 对普通用户的价值尚未验证；Scout 的社交边界问题；Solara 隐私合规挑战；Majorana 2 学术争议——这些都不是技术问题，而是"人的问题"。

值得关注

NVIDIA 入局 Windows on Arm 对高通构成的竞争压力；MXC 安全模型能否成为行业标准；Copilot 从工具到环境的进化路径。
